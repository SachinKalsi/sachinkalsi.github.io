Leave Δ at 0.15. At τ=0.01 the loss is already near zero, so training is done. At τ=0.05 the loss is still high, so training is not done. The same gap is enough for one and not for the other.

Drag Δ from 0 to 0.3. The τ=0.01 line drops very fast. The higher τ lines stay high.

Switch to the gradient tab. After the drop there is no force left, so the model stops changing.
